Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · One case: fade-out or big outbreak?

One case: fade-out or big outbreak? 500 runs, one flu-like case (R0 = 2) in 1,000 people. The histogram has two humps: many runs fade out almost at once; the rest infect close to the final-size-equation value (pink line). The white line is the mean of all runs, which matches no single run.

2 · How likely is one case to start a big outbreak?

How likely is one case to start a big outbreak? 1,000 runs. Theory from branching processes: about 1 − 1/R0 = 50% for R0 = 2 if illness length is very variable, about 58% for this model's more regular illness lengths. The rest die out by chance while numbers are tiny.

Isolating cases: how much does it help against a COVID-like disease? Sweep the share of cases who isolate when symptoms start. Because much spread happens before symptoms or from people with none, even 100% isolation cannot push R below 1 here. Try the same sweep with the Ebola-like disease: isolation alone can stop it.
