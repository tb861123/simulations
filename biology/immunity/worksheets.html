Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · How much bigger is the secondary response?

What this shows. Each run is one person (how fast their lymphocytes divide, how strong their phagocytes are and how many memory cells they keep each differ by about ±20%) infected twice with the same pathogen. The second antibody peak is about 8 times the first in the average person; people scatter around this mainly because they keep different numbers of memory cells. The mean comes out about 13% below the average person's value, and the spread is lopsided: in people whose first response is weak, the infection lasts so long that it stimulates the newly made memory cells during the first illness, which raises the 'primary' peak and lowers the ratio (a few go below 2). The average person is not the same as the average of the people. The standard error shows how well the mean is known.

2 · Time to the antibody peak: primary and secondary

What this shows. The secondary response peaks about 6 days after re-infection whatever the gap (gold), much sooner than the primary response's 2 weeks (grey dashed). Memory cells last for years in this model, so the gap does not matter; in reality memory for some pathogens fades, which is why some vaccines need boosters. Runs scatter only a little (about 0.1 day): in this model, how fast the clone grows changes the size of the response much more than its timing.

3 · Bigger doses, more illness: does vaccination help?

What this shows. With no immunity (each run: one person), small doses are often dealt with by phagocytes alone, but above about a tenth of the usual dose the pathogen multiplies faster than the non-specific response can cope, and the person is ill for several days until the antibodies arrive. The means sit above the average person because people with weak phagocytes are ill for much longer (if the first response fails, the infection stimulates a second, faster one a week later). The grey dashed line is a vaccinated person: almost no illness except from enormous doses, because memory cells respond within a day or two. Change Immune history to 'vaccinated' to swap the lines.

4 · Memory in the tissue (agent model)

What this shows. Each run is the full agent model: every virus, cell and phagocyte, with its own random numbers. With no memory, clearing the infection takes 3–5 days and depends on chance: a few viruses that slip into cells early can start a big outbreak. The gold line is the smooth model of the same response (antibodies and killer T cells as equations), and here theory and model disagree: in the patch of tissue the virus runs out of cells to infect (most are dead by day 2–3), so the infection burns out in about 3 days, before many antibodies arrive. The smooth model assumes there are always more cells to infect, so only the specific response can end it (about 10 days). Real infections lie between: this is why the agent model shows so much tissue damage. Change Immune history to 'had it before': cleared within about a day, with little damage.

5 · Skin as a barrier

What this shows. Each pathogen independently has a 5% chance of getting past intact skin, so the number that get in follows a binomial distribution: mean 0.05 × 200 = 10, SD √(200 × 0.05 × 0.95) ≈ 3.1 (blue curve). The histogram matches. Unbroken skin stops 95% here, which is why cuts, burns and needle-stick injuries are a risk.

6 · How many cells should you count? (PAG1)

What this shows. Each run counts n white cells from a healthy person's smear (true proportion of neutrophils 0.60). Small counts scatter widely: with 10 cells you might find 30% or 90%. The SD of the proportion shrinks as √(p(1 − p)/n): counting 4 times as many cells halves the scatter. This is why a differential count uses at least 100 cells, and why a single small count could wrongly suggest an infection.

7 · Antibiotic dose and zone size (PAG7)

What this shows. Below the critical amount there is no zone (6 mm is the disc itself). Above it, the zone grows with the logarithm of the amount, and more and more slowly, because the antibiotic spreads out in two dimensions as it diffuses. Plates differ (agar depth, lawn density) by about ±0.8 mm, and rulers read to ±0.5 mm, which is why several plates are used. Change Organism to MRSA: no zone with penicillin at any dose (resistance).
