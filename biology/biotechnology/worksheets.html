Biotechnology and Genetic Engineering · Teacher notesAnswers from a test run (fixed seed)

Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · Nitrogen and wheat yield

What this shows. Each run harvests eight plots and takes the mean. Yield rises steeply with the first 100 kg of nitrogen and then levels off: diminishing returns. Beyond about 200 kg N/ha the extra grain is worth less than the fertiliser, and much more nitrate is leached into rivers. Plots differ by about 8% (soil, drainage, pests), so means of eight scatter by about 3%. The same plots (random numbers) are used at every step, so if they happen to be a little below average every point sits a little below the line.

2 · Selective breeding: does heritability matter?

What this shows. Each run breeds a herd of 200 cows for 10 generations, keeping the best 20% each time. The more of the variation that is genetic (heritability h²), the faster the herd improves, because the cows chosen for high yields really do carry better alleles. The breeder's equation (yellow) overestimates the gain, more so at high h², because selection uses up genetic variation: alleles are lost from the herd.

3 · Fermenter temperature

What this shows. Each run grows GM bacteria for 48 hours at one temperature (inoculum ±10%). Insulin is made as the cells grow. Below about 25 °C the bacteria grow so slowly that the batch is nowhere near finished after 48 hours. From 25 to 40 °C every batch has used up the same glucose by 48 hours, so the yield is about the same (warmer batches simply finish sooner). Above about 42 °C the bacteria's enzymes begin to denature and the batch fails. Fermenters are held near the optimum so each batch finishes quickly; the water jacket removes the heat released by respiration.

4 · Aseptic technique: how many batches are lost?

What this shows. Without sterilising the vessel and filtering the air, each batch has about a 1% chance an hour of a contaminant getting in: about 38% of 48-hour batches. Out of 20 batches the number contaminated follows a binomial distribution (mean 7.6, SD 2.2). Tick 'Aseptic technique' in the table and run again: almost none are lost.

5 · PCR: copies against cycles (A level)

What this shows. On a log scale the number of copies rises in a straight line (exponential growth, ×1.95 a cycle at 95% efficiency), close to perfect doubling (grey) at first. After about 30 cycles the primers and nucleotides run out and the curve levels off at about 10¹² copies: the plateau. Early cycles with only a few copies vary from run to run, because whether each copy is copied is a matter of chance.

6 · Plate counts: how accurate? (A level)

What this shows. Each run dilutes a culture of 3 × 10⁸ cells per cm³ to 10⁻⁵ and spreads 0.1 cm³: about 270 colonies. The estimates scatter by about 9% (Poisson counting error, about √270 ≈ 6%, plus about 3% pipetting error at each of the five transfers), and on average they are about 10% too low (the yellow line is the true number) because clumps of cells give a single colony. Plate counts estimate colony-forming units, not cells.

7 · Reading a gel: estimating a fragment size (A level)

What this shows. Each run measures every ladder band and the unknown band to ±0.5 mm, draws the calibration line of log₁₀(size) against distance, and reads off the unknown. Estimates scatter by about ±7% (SD about 40 bp), which is why bands that differ by only a few base pairs cannot be told apart on an agarose gel (forensic labs use capillary electrophoresis).

8 · Immobilised lactase: flow rate (A level)

What this shows. Slower flow gives the milk more time in the column, so more lactose meets the enzyme: conversion = 1 − e^(−k × time). At 0.5 cm³ a minute almost all the lactose is converted; at 16 only about a quarter. Each run has a different batch of beads (±10% enzyme) and the glucose test strip is read to about ±5%.
