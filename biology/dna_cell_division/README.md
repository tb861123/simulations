# DNA, Protein Synthesis and Cell Division

A single, self-contained HTML file for iGCSE biology with an A level option.
It needs no install and no internet: **open `dna-cell-division.html` in Chrome
or Edge**.

★ Enhanced: built from `tools/kit/src/dna_cell_division.js` by `node build.js`
(run inside `tools/kit/`). Do not edit `dna-cell-division.html` by hand. The
earlier version and its worksheets are kept in [`original/`](original/).

- **Standard (iGCSE):** Pearson Edexcel International GCSE Biology (4BI1) 3(b):
  genes, chromosomes, DNA and base pairing, RNA, protein synthesis
  (transcription and translation), mitosis and meiosis, 46 and 23
  chromosomes, mutation.
- **Advanced (A level):** OCR A level Biology A (H420) 2.1.3, 2.1.6 (cell cycle,
  mitosis, meiosis with crossing over, root tip squash and mitotic index,
  PAG1) and 6.1.1 (types of mutation).

## Four views

- **🧬 DNA and proteins:** the start of the real human β-globin gene (HBB) as a
  twisting double helix; mRNA built by transcription; a ribosome translating
  codons into a chain of amino acids (coloured by R group) compared with the
  normal protein. Make a substitution, insertion or deletion at any base, a
  random substitution, or the sickle-cell mutation (GAG → GTG). Charts: base
  composition (A = T, C = G) and the mutation types you have made.
- **🔄 Cell cycle and mitosis:** an onion root tip cell (2n = 4) through G1, S,
  G2, prophase, metaphase, anaphase, telophase and cytokinesis, with homologous
  pairs coloured. Charts: DNA per cell (2C → 4C → 2C) and phase durations.
- **🔬 Root tip squash:** a stained field of view at any distance from the tip;
  count it to get the mitotic index; results along the root against the
  model; at A level, phase durations from the counts.
- **🎲 Meiosis:** 2, 3 or 4 pairs through meiosis I and II to four gametes;
  gametes collected into a bar chart of the 2ⁿ kinds; 2ⁿ up to humans. A level:
  crossing over.

## The model and its simplifications

Standard genetic code; cell cycle of about 20 hours (G1 6, S 6, G2 5, mitosis
3 h); mitotic index from the phase durations and a smooth fall 1.5–2 mm from
the tip; independent assortment (and one crossover per pair at A level). Only
the start of one gene, no introns or regulation. The earlier version's
replication, Meselson–Stahl and lac operon views are not included.
