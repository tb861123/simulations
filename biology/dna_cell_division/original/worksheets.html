Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · Meselson–Stahl: hybrid DNA each generation

What this shows. Each run follows a culture of 2000 DNA molecules from ¹⁵N into ¹⁴N and spins a random sample of 200. Semi-conservative copying predicts 100% hybrid after one generation, then 50%, 25%, 12.5% … (2 hybrid molecules out of 2^g), with the rest light. The grey line is the conservative prediction: never any hybrid. Runs scatter because each sample of 200 is random (about ±3.5 percentage points at 50%) and because the culture is diluted at random each generation.

2 · Counting cells: how variable is the mitotic index?

What this shows. Each run counts 100 cells near the tip. The true mitotic index there is about 12.6%, but a careful counter misses very early prophase, so expects about 10.5%. Single counts of 100 cells scatter a lot: the standard deviation is √(p(1 − p) ÷ 100) ≈ 3 percentage points, so two students' counts of 100 cells can easily differ by 6 points. Counting more cells (or several fields) narrows the spread as 1 ÷ √N.

3 · Mitotic index along the root

What this shows. Near the tip (the meristem) about one cell in nine is visibly dividing; from about 1.5 mm the cells start to elongate and stop dividing, and by 3 mm almost none divide. The yellow line is what a careful counter should see; the grey line includes very early prophase cells that look like interphase. Means sit on the yellow line; single runs scatter by about ±2 points.

4 · How many different gametes?

What this shows. Each run makes 200 gametes by meiosis (independent assortment only) and counts the different combinations of whole chromosomes. With few pairs every one of the 2ⁿ types turns up; by n = 8 (256 types) some are missing from 200 gametes; by n = 12 (4096 types) almost every gamete is different. The yellow line is the expected number 2ⁿ(1 − (1 − 2/2ⁿ)⁵⁰): 200 gametes come from only 50 cells, and the four gametes from one cell are two pairs of complementary types (e.g. MPM, MPM, PMP, PMP), so there are fewer kinds than 200 independent gametes would give. Humans have n = 23: 8.4 million types, before crossing over. Tick 'Crossing over' in the table to see nearly every gamete become unique even when n = 1.

5 · Random substitutions: how many change the protein?

What this shows. Each run makes 50 random single-base substitutions (outside the start codon) and translates each with the real genetic code. About a quarter are silent, because the code is degenerate: many third-base changes give the same amino acid. The yellow line is worked out from every one of the 153 possible substitutions. The spread is binomial: about ±6 percentage points for 50 substitutions.

6 · Mutagens: more dose, more mutated genes

What this shows. Each run copies the 54-base gene 1000 times with a chance μ per base of a copying mistake; a mutagen multiplies that chance by (1 + dose). The number of mutated copies rises almost in proportion to the dose at first, then a little less (a copy that already has one mutation is not counted twice). Each step re-uses the same 20 random-number streams, so the means at neighbouring doses tend to sit above or below the line together. Rates are scaled up hugely so they show: real copying makes about one mistake per 10⁹–10¹⁰ bases.

7 · lac operon: mRNA against lactose

What this shows. Each run follows one E. coli cell for 60 minutes and counts its mRNA molecules. Without lactose the repressor is on the operator 99% of the time: almost no mRNA. Lactose pulls the repressor off, and the mean rises steeply (an S-shaped switch) to about 11 molecules. Single cells scatter a lot (about ±3), because mRNA is made and broken down one molecule at a time and the operator flips at random. Tick 'Glucose present' to see transcription stay low (catabolite repression, beyond the H420 wording).
