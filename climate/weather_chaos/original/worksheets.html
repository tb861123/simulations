Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · How long does a Lorenz-63 forecast last?

Theory: a difference δ grows like δ·e^(λt), so the forecast fails when δ·e^(λt) reaches the threshold: t = ln(threshold/δ)/λ, with λ = 0.906. The measured times scatter because the real growth rate varies from place to place on the attractor (some starting points are more predictable than others). In the test run the measured mean was about 1.5 time units (≈10%) BELOW this theory, many standard errors away, so the simple formula is not the whole story: a likely cause is that an error in a random direction grows faster than e^(λt) for a short time before it lines up with the fastest-growing direction (transient growth). That explanation was not separately tested. The standard error shrinks as 1/√runs. Mean and SD describe the scatter between starting points; the standard error tells you how well the mean is known.

2 · Do 1000× better measurements give 1000× longer forecasts?

No. The forecast time rises only by about ln(10)/λ ≈ 2.5 time units for every factor of 10 improvement, because errors grow exponentially. The measured slope matches this; the measured times all sit a roughly constant 1 to 2 time units below the theory line (see the previous experiment). Making the initial data a billion times better buys only about 20 extra time units (roughly 8 error-doubling times). This is why weather forecasts have a limit of about two weeks, however good the instruments.

3 · How chaotic is Lorenz 96 as the heating F increases?

For small F the weather settles to a steady state and tiny errors die away (negative growth rate). The growth rate crosses zero near F ≈ 3 to 4 and then rises steadily with F (clearly chaotic from F ≈ 5). At F = 8 the literature value for 40 stations is about 1.67 per time unit, an error doubling time of about 2.1 days at 5 days per unit, which is close to what is observed in the real atmosphere. The exponent is measured by following two nearby runs and rescaling their separation (Benettin method).

5 · How much does averaging an ensemble improve a forecast?

If the truth and the members are equally likely possibilities, the ensemble mean has mean-square error σ²(1 + 1/N), while a single member has 2σ². The ratio of RMS errors is therefore √((1 + 1/N)/2): 0.79 for N = 4 and tending to 0.71 for many members. Compare like with like: the ratio uses the AVERAGE squared errors over all runs (averaging the ratio run by run is biased low), and its standard error comes from resampling the runs (bootstrap). Averaging removes unpredictable details, which is why forecasters run ensembles.
