Ice–Albedo Tipping Points · Teacher notesice-albedo.html

Teacher notes

Investigation 1: Today's ice caps

What to look for: The ice edge settles near 64° (ice where the yearly mean is below −10 °C); the model's global mean is about 11.5 °C, a few degrees cooler than the real Earth. Ice reflects about 62% of sunlight, open ocean and land about 30%.

Investigation 2: The ice–albedo feedback

What to look for: Cooling → more ice → more sunlight reflected → more cooling: a positive feedback. A few % less sunlight moves the ice edge from 64° to about 43°.

Investigation 3: Snowball Earth

What to look for: Below about 93% the ice caps run away to the equator: the whole planet freezes (a snowball) at about −42 °C. There is no stable ice-cap climate here: the system has tipped.

Investigation 4: Can you get back?

What to look for: No: the white planet reflects so much that it stays frozen until the Sun is about 131% of today's. The climate does not retrace its path: hysteresis. Geologists think real snowball Earths ended when volcanic CO₂ built up for millions of years.

Investigation 5: Hysteresis loop

What to look for: Going down, the planet follows the ice-cap branch until it falls off the fold at 93%. Going up, it stays frozen until 131% and then jumps to ice-free. Two different states at the same Sun: which you are in depends on history.

Investigation 6: CO₂ to escape

What to look for: CO₂ traps infrared and so warms the planet in the same way as a brighter Sun. It has to rise to tens of thousands of ppm before the equator thaws, then the ice melts back rapidly.

Investigation 7: Small ice cap instability A level

What to look for: No: once the cap is small (edge beyond about 80°) it becomes unstable and disappears suddenly (the curve's slope reverses near the pole). Small ice caps cannot be stable in this model: the ice-free state takes over.

Investigation 8: Heat transport A level

What to look for: Less heat carried polewards: hotter equator, colder poles, so a bigger temperature difference; the ice caps are larger and the climate tips into a snowball at a different Sun %.

Batch experiment 1: Hysteresis: starting warm

The ice-cap branch until about 93%, then a jump to snowball (0°). Compare the next experiment, which starts from a snowball.
Result from a test run: 90: 0 ± 0 · 92: 0 ± 0 · 93: 0 ± 0 · 94: 38 ± 0 · 96: 47.5 ± 0 · 98: 54.7 ± 0 · 100: 63.7 ± 0 · 104: 90 ± 0 · 110: 90 ± 0 · 120: 90 ± 0 · 130: 90 ± 0 · 135: 90 ± 0 (mean ± SE, 1 runs each)

Batch experiment 2: Hysteresis: starting from a snowball

It stays frozen all the way up to about 131%, then jumps straight to ice-free. Between 93% and 131% two climates are possible: hysteresis.
Result from a test run: 90: 0 ± 0 · 92: 0 ± 0 · 93: 0 ± 0 · 94: 0 ± 0 · 96: 0 ± 0 · 98: 0 ± 0 · 100: 0 ± 0 · 104: 0 ± 0 · 110: 0 ± 0 · 120: 0 ± 0 · 130: 90 ± 0 · 135: 90 ± 0 (mean ± SE, 1 runs each)

Batch experiment 3: CO₂ and global temperature

Each doubling of CO₂ warms the planet by a similar amount (the forcing ∝ log CO₂), boosted by ice melting. At low CO₂ (ice-age levels) the ice spreads far.
Result from a test run: 180: 5.95 ± 0 · 280: 8.76 ± 0 · 420: 11.5 ± 0 · 560: 15.4 ± 0 · 840: 16.4 ± 0 · 1120: 17.2 ± 0 · 1680: 18.2 ± 0 (mean ± SE, 1 runs each)

Batch experiment 4: Heat transport and the equator–pole difference

Stronger transport evens out the temperatures. Weak transport gives a very cold pole (and bigger ice caps).
Result from a test run: 0.2: 77.1 ± 0 · 0.3: 64.4 ± 0 · 0.45: 47 ± 0 · 0.6: 30.3 ± 0 · 0.8: 25 ± 0 · 1: 21.3 ± 0 (mean ± SE, 1 runs each)

Batch experiment 5: Near the edge: weather noise

Close to a tipping point, random fluctuations can push the climate over the edge: the closer to the edge and the noisier the weather, the more likely.
Result from a test run: 0: 0 ± 0 · 5: 0 ± 0 · 10: 0.4 ± 0.163 · 15: 0.8 ± 0.133 · 20: 0.8 ± 0.133 · 30: 0.9 ± 0.1 (mean ± SE, 10 runs each)

Batch experiment 6: Ice albedo and the tipping point

Brighter ice makes the feedback stronger, so the planet tips into a snowball with less dimming.
Result from a test run: 0.45: 81.6 ± 0 · 0.5: 84.8 ± 0 · 0.55: 87.9 ± 0 · 0.6: 90.9 ± 0 · 0.62: 92.1 ± 0 · 0.65: 93.9 ± 0 · 0.7: 96.9 ± 0 · 0.75: 99.8 ± 0 (mean ± SE, 1 runs each)
