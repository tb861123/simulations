# Strings: Pluck, Bow, Strike

Explore string length, tension, mass and playing position with audible harmonic models.

Open `strings.html` in Chrome or Edge. Works offline. Press Play to enable sound.

## Investigation
Halve the string length. Predict the pitch before playing. Pluck at the centre, then near the bridge, and compare the spectrum.

## Model
An ideal string has f₁ = √(T/μ)/(2L), with partials at n × f₁. Playing position changes how strongly each mode is excited.

Ideal flexible string with fixed ends. Bow mode uses sustained harmonic synthesis, not a friction solver. Strike mode is a simplified initial-velocity excitation. No instrument body or string stiffness is modelled.
