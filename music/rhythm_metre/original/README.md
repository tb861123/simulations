# Rhythm and Metre

Build a two-bar pattern with subdivisions, accents, rests and swing.

Open `rhythm_metre.html` in Chrome or Edge. Works offline. Press Play to enable sound.

## Investigation
Place an accent on each bar’s first beat, then move an accent off the beat. Compare the same pattern at different tempos. Try 3 subdivisions per beat, then 2 with swing.

## Model
Tempo controls beat duration. Metre groups beats; subdivisions divide them. Each cell cycles rest → hit → accent. Swing delays the second subdivision of each pair.

Two-bar step sequencer with quarter-note beats. Swing applies only to even subdivision counts; odd counts remain even. This is a timing model, not a model of expressive human performance.
