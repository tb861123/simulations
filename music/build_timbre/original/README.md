# Build a Timbre

Mix eight harmonics and shape attack and decay to design a sound.

Open `build_timbre.html` in Chrome or Edge. Works offline. Press Play to enable sound.

## Investigation
Keep the pitch fixed. Remove the fundamental: can you still hear a pitch? Compare short and long attacks with the same spectrum.

## Model
Timbre depends on spectral content and how it changes over time. Harmonics occur at integer multiples of the fundamental; the fundamental can be absent.

Additive synthesis with eight harmonics and a shared attack/decay envelope. Presets are teaching approximations, not recordings or full instrument models. Spectral balance is static during each note.
