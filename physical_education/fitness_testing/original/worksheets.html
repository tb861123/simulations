Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · Test and retest: how big is the typical error?

What this shows. Each performer jumps once, then again a week later. Even with a perfect protocol the scores differ, because the body changes from day to day and each jump and each chalk mark varies. The differences form a bell curve centred on zero; its SD ÷ √2 is the typical error (about 2.6 cm here, in line with published values of 2–3 cm). Untick 'Practice attempt' and run again: the whole curve moves up, because people jump higher the second time just from having done it (the learning effect, a systematic bias).

2 · How many drops give a reliable ruler-drop score?

What this shows. A single ruler drop is a poor measure: the error is about 3–4 cm (about 0.02 s). Averaging several drops cuts the trial-to-trial part of the error by √n, so on log–log axes the line starts with a gradient near −½ and then flattens: the day-to-day part does not shrink however many drops you average on one day. Three to five drops get most of the benefit. Points scatter because each run is a new performer with random errors; the theory converts seconds to centimetres near a 0.19 s reaction, so it is slightly approximate.

3 · Can a retest show a real training improvement?

What this shows. Every performer in a squad of 20 truly improves by the same amount; we count how many retests show a gain bigger than the smallest worthwhile change (SWC, here about 0.45 levels). With no real change about a quarter still 'improve' by luck; with a real gain equal to the SWC only half do; you need a true gain of about 1.5 levels before nearly everyone's retest shows it. Measurement error (typical error about 0.5 levels) hides real changes. The theory is the normal curve Φ((Δ − SWC) ÷ (√2 TE)); dots scatter because each squad is only 20 people.

4 · Ruler drop: distance and reaction time

What this shows. The ruler falls freely, so the distance grows with the square of the time: d = ½gt². On log–log axes the gradient is 2: double the reaction time, four times the distance. So t = √(2d ÷ g): a 20 cm catch is 0.20 s, a 10 cm catch 0.14 s. Each point is one drop, which varies by about 0.02 s, so the dots scatter; at slow reactions the same timing error makes a bigger distance error. The means can sit a little off the line: averaging a square gives slightly more than the square of the average (pushing them up), and the same 30 random drops are used at every step, so any luck in those drops moves all the points together.

5 · Does the bleep test measure VO₂ max?

What this shows. Performers with known (lab) VO₂ max do the bleep test, and the published equation turns their level into a predicted VO₂ max. On average the prediction follows the true value (gradient about 1), so the test is valid for aerobic capacity, but individuals scatter by about ±3.5 ml/kg/min: running economy, turning, pacing and motivation also affect the level reached, and the score only goes up in whole shuttles. It is an INDIRECT measure; the direct one is gas analysis in a lab.
