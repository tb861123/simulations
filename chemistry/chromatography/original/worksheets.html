Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · How precise is one Rf measurement?

What this shows. The true Rf is 0.38. Single measurements scatter with an SD of about 0.01 (the blue curve is the prediction from the errors): reading each distance to the nearest mm with a ±0.5 mm reading error, and judging the centre of a spot about 3 mm across. So two students who both measure carefully can disagree in the second decimal place. An Rf is usually quoted to 2 decimal places; to tell two substances apart their Rf values need to differ by more than about 0.03.

2 · Rf error against ruler error

What this shows. The average size of the error in Rf grows with the ruler error, following the theory line (the average size of a normal error is 0.8 × its SD). Even a perfect reader has some error (left end) because readings are rounded to the nearest mm and the centre of a blurred spot is a judgement. Errors scatter widely from run to run; the dots are the means of 200 measurements. Every step reuses the same 200 sets of random numbers (so only the ruler error changes), and this set happens to run about 10% large, so all the points sit a little above the line together: a reminder that even 200 runs have sampling error. At 0 mm the points sit a little above the line because rounding to the nearest mm is not a normal (bell-shaped) error.

3 · Bigger spots: worse separation?

What this shows. Sunset yellow (Rf 0.48) and ponceau 4R (Rf 0.55) end up only 0.56 cm apart. With 1–2 mm spots the resolution is about 1 (just separate: the dashed line). As the starting spot gets bigger the spots overlap more: by 10 mm the resolution is about 0.5 and they look like one smudge. The spreading during the run (diffusion and flow) sets a limit, so even a tiny spot cannot do better than about 1.05 here; running further (a longer paper) separates them more. Scatter comes from hand-made spots varying in size (±20%).

4 · Does Rf depend on how far the solvent runs?

What this shows. No: the mean Rf stays at 0.38 whether the front runs 3 cm or 12 cm, because the spot and the front both move in proportion. That is what makes Rf useful: it does not depend on how long you leave the paper. But the spread is much bigger for short runs (the same 1 mm reading error is a bigger fraction of a short distance), so run the solvent as far as you can.

5 · How fast does the solvent rise?

What this shows. Capillary flow slows down as the solvent climbs (the Lucas–Washburn law): height = √(k × time), with k = 3.0 cm²/min for water on this paper. On log–log axes it is a straight line with gradient 0.5: ten times longer gives only √10 = 3.2 times higher. That is why the last few cm take the longest. The scatter is pieces of paper soaking up solvent at slightly different speeds (±5%) and reading to the nearest mm.

6 · Which solvent?

What this shows. The same dye has a different Rf in each solvent: 0.90 in water, 0.93 in salt water, 0.35 in ethanol, 0.02 (stuck on the baseline) in the non-polar propanone mixture and 0.45 in butanol/ethanoic acid/water. Brilliant blue is a salt-like, very water-soluble dye, so it races up with water but barely dissolves in a non-polar solvent. So an Rf value only means something if you say which solvent (and paper) was used.
