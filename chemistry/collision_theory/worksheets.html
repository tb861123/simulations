1 · Arrhenius plot: can we measure Ea?

Arrhenius plot: can we measure Ea?

Each point is the initial rate at one temperature. Plotting ln(rate) against 1/T gives a straight line whose gradient is −Ea/R, so you can work out Ea without ever seeing a particle. That is how chemists measure activation energies.

The points scatter because each run has only a dozen or so reactions, which happen at random moments. The fitted Ea is a little above the set value: hotter particles also collide more often, adding ½RT.

2 · What is the order with respect to A?

What is the order with respect to A?

On a log–log graph, rate ∝ [A]ⁿ becomes a straight line with gradient n, the order of reaction. Collision theory says the collisions between A and B are proportional to the number of A, so n = 1.

Small numbers of particles give few reactions, so those points scatter most.

4 · Does the fraction that succeed follow e^(−Ea/RT)?

Does the fraction that succeed follow e^(−Ea/RT)?

Every collision between A and B is recorded, and we count the fraction that react. Maxwell–Boltzmann theory says the fraction with enough energy is e−Ea/RT, so ln(fraction) against Ea is a straight line with gradient −1/RT.

To keep the mixture the same throughout, these runs count each successful collision but leave the particles unchanged. At high Ea only a handful of collisions succeed, so those points scatter more.

5 · How much do repeat runs vary?

How much do repeat runs vary?

Every run starts with the same numbers of particles at the same temperature, but the particles start in different random places. The time for half of them to react changes from run to run.

The spread (SD) is what you would see between class experiments. The mean of many runs gets close to the collision-theory value: the standard error shrinks as 1/√n.

6 · Lumps or powder?

Lumps or powder?

The same 64 solid particles are kept as one lump or broken into smaller pieces. Only surface particles can be hit, so more pieces means more collisions and a faster reaction. This is why powders react faster than lumps, and why flour dust can explode.

The theory line uses the length of exposed surface around the lumps.
