Rf Values

Key Equations

Rf = distance moved by spot ÷ distance moved by solvent
Measure both distances from the baseline
Rf is always between 0 and 1
More soluble components travel further (higher Rf)
Each substance has a characteristic Rf → used to identify it
Exam Practice

[2 marks] Explain why the baseline on a chromatography paper is drawn in pencil.

Pencil (graphite) is insoluble in the solvent [1]; so it will not dissolve and move up the paper, which would interfere with the results [1].

[3 marks] A dye moves 4.5 cm up the paper while the solvent front moves 9.0 cm. Calculate the Rf value and state what Rf can be used for.

Rf = distance moved by dye ÷ distance moved by solvent = 4.5 ÷ 9.0 [1]; Rf = 0.5 [1]; Rf values are characteristic of a substance and can be used to identify it (by comparison with known values) [1].

[2 marks] Explain why the different dyes in the ink separate as the solvent moves up the paper.

The dyes have different solubilities in the solvent (and different attractions to the paper) [1]; more soluble dyes are carried further up the paper, so they separate [1].
