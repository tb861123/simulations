Exam Practice

[3 marks] Sodium has atomic number 11 and mass number 23. State the number of protons, neutrons and electrons in a neutral sodium atom.

Protons: 11 [1]; Neutrons: 12 [1]; Electrons: 11 [1].

[2 marks] Define the term isotope.

Atoms of the same element with the same number of protons [1]; but different numbers of neutrons [1].

[2 marks] Sodium (electron configuration 2,8,1) forms an ion. State the electron configuration of the sodium ion and its charge.

Electron configuration: 2,8 [1]; Charge: 1+ [1].
