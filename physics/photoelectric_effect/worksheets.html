Photoelectric Effect · Teacher notesAnswers from a test run (fixed seed)

Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · Stopping voltage against frequency

What this shows. Millikan's experiment. Each point is a stopping voltage read on a voltmeter with a random error (SD 0.1 V). The means lie on the theory line V_s = (h/e)(f − f₀), a straight line: the best-fit gradient gives h within about 1%, and the intercept gives caesium's work function. The scatter at each frequency is the same, because the meter error does not depend on f.

2 · Planck's constant from LEDs

What this shows. Each run is one student's experiment: stopping voltages for six LEDs (365–525 nm), using each LED's labelled wavelength, then h = e × gradient. Each LED's real peak wavelength differs from its label by a few nm and the meter has a small error, so results scatter around 6.63 × 10⁻³⁴ J s with an SD of a few per cent. The mean is close to the true value: the errors are random, not systematic.

3 · Work function from the intercept

What this shows. The same LED method on sodium: extend the straight line back to f = 0 and the intercept is −φ/e. The results scatter around 2.36 eV, more widely than h does, because a long extrapolation back to f = 0 magnifies any error in the gradient.

4 · Does brighter light give a bigger V_s?

What this shows. Wave theory predicted that brighter light would give electrons more energy and need a larger stopping voltage. The results say no: V_s stays at (h/e)(f − f₀) = 1.21 V at every intensity, with only the meter's random scatter. Each electron gets the energy of one photon, whatever the number of photons.

5 · Is the current proportional to intensity?

What this shows. Doubling the intensity doubles the number of photons per second and so doubles the number of electrons: the saturation current is proportional to intensity (a straight line through the origin, about 32 nA per unit). The scatter comes from counting a random (Poisson) number of electrons in each 10 ns window: it grows as √N, so it is a smaller fraction of the current for bright light.

6 · Is there a threshold frequency?

What this shows. Below f₀ = 5.08 × 10¹⁴ Hz (red and orange light) the current is exactly zero, however long you wait. Above it the current jumps to its full value at once. With the same number of photons per second, the current does not depend on frequency above the threshold: frequency changes the electrons' energy, not their number.
