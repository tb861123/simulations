Atomic Spectra and Energy Levels · Teacher notesAnswers from a test run (fixed seed)

Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · Do the Balmer lines fit Rydberg's formula?

What this shows. Each point is a line measured with a diffraction grating (d sin θ = λ) with a random angle error of 0.05°. The means sit on Rydberg's formula 1/λ = R(1/2² − 1/n²): 656, 486, 434, 410 nm… The lines crowd together towards the series limit at 365 nm (n = ∞), because the upper levels get closer and closer together.

2 · Measure the Rydberg constant

What this shows. Each student measures H-α to H-δ, plots 1/λ against 1/n² and takes R = −gradient. The results scatter around 1.097 × 10⁷ m⁻¹ with an SD of about 1%. The four lines span only a small range of 1/n² (0.028 to 0.111), so small angle errors move the gradient noticeably.

5 · Finer grating, better wavelength?

What this shows. The same 0.05° angle error is a smaller fraction of a big angle. With more lines per mm the H-α line is diffracted further (sin θ = λ/d), so the spread of measured wavelengths (the error bars) shrinks: about 9 nm at 100 lines/mm, about 0.5 nm at 1200. The mean stays on 656.5 nm either way.

6 · How many photons can we see?

What this shows. Each atom starts at n = 6 and drops by random jumps to the ground state, giving out one photon per jump. Only Balmer jumps (to n = 2) give visible light; every atom ends with an ultraviolet Lyman photon. On average only about a fifth of the photons (21.9%) are visible, and the result scatters from run to run because the jumps are random. (Real jump probabilities are not all equal.)
