Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · How far ahead can we predict a chaotic pendulum?

What this shows. 100 random big-swing starts, each with a twin 0.001° away. The time until they differ by 10° varies a lot from start to start, because some swings are more chaotic than others. Each run's own λ predicts its horizon reasonably well; the measured time is usually a little longer, because the gap first has to line up with the fastest-stretching direction before it grows exponentially.

2 · Does a 1000× smaller error give 1000× longer?

What this shows. No! Each 10× smaller starting error adds only the same fixed amount of time, ln(10)/λ, so the points fall on a straight line against log δ. Making the measurement a billion times better only buys a few times longer. The same random starts are used at every step, so the scatter at each step comes from how chaotic each start is: less chaotic starts stay predictable for longer. (Runs are stopped at 60 s.)

3 · When does chaos switch on?

What this shows. For small starting angles λ is close to 0 (the gap grows only slowly, so a 40 s run gives a small positive number rather than exactly 0). Somewhere between about 70° and 90° the pendulum gains enough energy for the lower arm to flip over and λ jumps up: chaos switches on. Near the boundary some starts are chaotic and some are not, so the scatter is large.

5 · When does the small-angle formula fail?

What this shows. 2π√(L/g) assumes sin θ ≈ θ. That is within 1% up to about 20°, but a 90° swing takes 18% longer and a 170° swing more than twice as long, because the pendulum lingers near the top. The exact formula (grey dashed) fits every point.

6 · Can we trust the computer?

What this shows. With no damping, energy should stay exactly constant. After 60 s of wild chaotic motion (60,000 RK4 steps) the drift is around a millionth of a per cent or less. The chaos is not caused by rounding errors in the computer: the starting difference of 0.001° is millions of times bigger than the numerical error.
