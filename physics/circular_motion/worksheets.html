Circular Motion · Teacher notesAnswers from a test run (fixed seed)

Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · Whirling bung: is F = mω²r?

What this shows. A rubber bung is whirled on a string through a glass tube; a 100 g mass hangs from the other end, so the tension is Mg = 0.98 N. Each run times 10 turns with a stopwatch, finds ω = 2π/T and works out mω²r. The results scatter around Mg, as F = mω²r predicts. The spread comes from reaction time: F depends on 1/T², so a 1% timing error becomes a 2% force error. Timing more turns makes it smaller.

2 · Bung period against radius

What this shows. With the same hanging mass, the tension is the same at every radius, so mω²r is fixed and ω² ∝ 1/r: T = 2π√(mr/Mg). On log–log axes this is a straight line of gradient 0.5. The error bars are the stopwatch's reaction-time scatter.

5 · Loop the loop: is √(5gr) the minimum?

What this shows. Each run solves the motion step by step and records how far round the ball gets while the string stays taut. Below √(2gr) = 6.3 m/s it just swings like a pendulum (below 90°). Between 6.3 and 9.9 m/s it goes above the centre but the string goes slack before the top and the ball falls inside the loop. From √(5gr) = 9.9 m/s it goes all the way round (360°). The model agrees with the theory from energy and F = mv²/r at every speed.

6 · Banked bend: fastest safe speed

What this shows. Each run is a car whose tyre grip μ varies (mean 0.7, SD 0.08). Banking raises the fastest safe speed: the slope provides part of the centripetal force, and the extra normal force increases the friction available. The spread grows with the angle because v_max becomes very sensitive to μ. The dashed line is the ideal speed, where no friction is needed at all.
