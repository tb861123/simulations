Gas in a Box · Teacher notesAnswers from a test run (fixed seed)

Teacher notes

The results below come from one test run with the default seed, so a class should get the same numbers. A different seed gives slightly different values within the scatter.

1 · Does pV = NkT hold?

What this shows. Each run measures pressure from wall hits for 300 ps. The average is close to 1 but a few per cent higher, because molecules take up a little room and get in each other's way (the yellow line includes this). Single runs scatter by about 1% because only a few thousand wall hits are counted. The model lands about 1% below the yellow line: collisions are found one small time step late, after the discs have overlapped slightly, so they act a little smaller than their real size.

2 · Boyle's law: does p ∝ 1/V?

What this shows. On log–log axes p ∝ 1/V is a straight line of gradient −1. Small boxes are a little above the ideal line: the molecules fill more of the space, so they collide with the walls slightly more often.

3 · Pressure law: does p ∝ T?

What this shows. Pressure rises in a straight line with kelvin temperature and would reach zero at 0 K. Faster molecules hit the walls harder and more often, so p ∝ ⟨½mv²⟩ ∝ T.

5 · Brownian motion: does ⟨r²⟩ = 4Dt?

What this shows. Each run follows the big particle for 800 ps and finds D from the gradient of mean square displacement against time (÷ 4 in 2D). One run gives a rough value, because the walk is random; the average of many runs is close to theory. The theory ignores the gas swirling along with the particle, which in 2D changes D by around 10%.

6 · Mixing: do more molecules mix slower?

What this shows. More molecules means a shorter mean free path, so each molecule is knocked back more often and diffuses more slowly: D ∝ 1/n, so mixing time ∝ N. Expect agreement only to within about 20%: the box is just a few mean free paths wide (the theory assumes many), and "80% mixed" is judged from a noisy count, so with few molecules random fluctuations can make it early or late.

7 · Light vs heavy: is v ∝ 1/√m?

What this shows. At the same temperature every molecule has the same average kinetic energy, so ½mv² is fixed and v ∝ 1/√m: a straight line of gradient −0.5 on log–log axes. Helium molecules move about 2.6 times faster than nitrogen.
