Teacher notes

Investigation 1: Chord to tangent

What to look for: The chord gradient is 2 + h, so it approaches 2 as h → 0: f'(1) = 2. In general [(x + h)² − x²]/h = 2x + h → 2x. This is differentiation from first principles.

Investigation 2: The gradient function

What to look for: A parabola, 3x²: always positive or zero, zero at the origin (a point of inflection), and the same for x and −x.

Investigation 3: Stationary points

What to look for: f'(x) = 3x² − 3 = 0 at x = ±1. f''(x) = 6x: f''(−1) = −6 < 0, a maximum at (−1, 3); f''(1) = 6 > 0, a minimum at (1, −1).

Investigation 4: Increasing and decreasing

What to look for: Increasing where f'(x) > 0: x < −1 and x > 1 (green). Decreasing for −1 < x < 1 (red).

Investigation 5: Area under a curve

What to look for: ∫₀² x² dx = [x³/3]₀² = 8/3 ≈ 2.667. More, thinner strips give a better estimate: area is the limit of a sum.

Investigation 6: Below the axis

What to look for: Parts below the x-axis give a negative contribution to the integral. To find the total area, integrate each part separately and add the sizes.

Investigation 7: Gradient of sin x from first principles A level

What to look for: The gradient function is cos x. First principles uses sin h/h → 1 and (cos h − 1)/h → 0 as h → 0, which are only true in radians.

Investigation 8: Concave, convex and inflection A level

What to look for: f''(x) = 6x: concave for x < 0, convex for x > 0, point of inflection at (0, 1) where f'' changes sign. It is not a stationary point (f'(0) = −3).

Investigation 9: Trapezium rule: over or under? A level

What to look for: An overestimate: eˣ is convex (curves upwards), so every trapezium's top lies above the curve. For a concave curve (like ln x) it underestimates.

Batch experiment 1: How fast does the chord gradient converge?

The error is 3h + h², so it shrinks in proportion to h for small h: halving h halves the error.
Theory (3h + h²): 1: 4 · 0.8: 3.04 · 0.6: 2.16 · 0.4: 1.36 · 0.2: 0.64 · 0.1: 0.31 · 0.05: 0.153
Result from a test run: 1: 4 ± 0 · 0.8: 3.04 ± 0 · 0.6: 2.16 ± 0 · 0.4: 1.36 ± 0 · 0.2: 0.64 ± 0 · 0.1: 0.31 ± 0 · 0.05: 0.153 ± 0 (mean ± SE, 1 runs each)

Batch experiment 2: Trapezium rule error

Doubling n divides the error by 4: the error is proportional to h². The formula comes from (h²/12)(f'(b) − f'(a)).
Theory (π²/(6n²)): 2: 0.411 · 3: 0.183 · 4: 0.103 · 6: 0.0457 · 8: 0.0257 · 12: 0.0114 · 16: 0.00643
Result from a test run: 2: 0.429 ± 0 · 3: 0.186 ± 0 · 4: 0.104 ± 0 · 6: 0.0459 ± 0 · 8: 0.0258 ± 0 · 12: 0.0114 ± 0 · 16: 0.00643 ± 0 (mean ± SE, 1 runs each)

Batch experiment 3: Left rectangles against the trapezium rule

Rectangles converge only like 1/n; the trapezium rule like 1/n². That is why the trapezium rule is used.
Theory ((e − 1)/(2n)): 2: 0.43 · 4: 0.215 · 6: 0.143 · 8: 0.107 · 12: 0.0716 · 16: 0.0537 · 24: 0.0358
Result from a test run: 2: 0.394 ± 0 · 4: 0.206 ± 0 · 6: 0.139 ± 0 · 8: 0.105 ± 0 · 12: 0.0706 ± 0 · 16: 0.0531 ± 0 · 24: 0.0355 ± 0 (mean ± SE, 1 runs each)

Batch experiment 4: Random cubics: how many stationary points?

f'(x) = 0 is a quadratic: two stationary points if its discriminant 4b² − 12c > 0, none if it is negative. This happens two-thirds of the time.
Theory (2 × P(b² > 3c) = 4/3): 1.33
Result from a test run: mean 1.33, SD 0.125, SE 0.00881 from 200 runs

Batch experiment 5: Area by random darts

A Monte Carlo estimate: unbiased, but noisy (SD √(p(1−p)/400) ≈ 0.024). Strips are far more accurate for one variable; random points win in many dimensions.
Theory (1/3): 0.333
Result from a test run: mean 0.334, SD 0.0242, SE 0.00139 from 300 runs
