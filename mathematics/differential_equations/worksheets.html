Differential Equations · Teacher notesdifferential-equations.html

Teacher notes

Investigation 1: Reading a slope field

What to look for: The gradient is zero along y = 2. Every solution approaches y = 2: above it they fall, below it they rise. The general solution y = 2 + Ae^(−2x) shows why.

Investigation 2: One family, many particular solutions

What to look for: No: through each point there is exactly one gradient, so solution curves can't cross. Each starting point (boundary condition) picks out one value of A in y = x − 1 + Ae^(−x).

Investigation 3: Euler's method

What to look for: Euler uses the gradient at the START of each step, so it falls behind a curve that gets steeper. Error at x = 3: about 8.7 with h = 0.5, 5.5 with h = 0.25 … roughly halving each time (the method is first order).

Investigation 4: Separating variables: circles

What to look for: y dy = −x dx gives x² + y² = c: circles. Euler always steps along the tangent, which points outwards, so it spirals out and gets worse each lap.

Investigation 5: Logistic growth

What to look for: y = 0 and y = 2 (gradient zero). y = 2 is stable: nearby solutions move towards it. y = 0 is unstable: a tiny positive y grows away from it.

Investigation 6: Simple harmonic motion A level

What to look for: x'' = −ω²x has auxiliary roots ±iω, so x = A cos ωt + B sin ωt with period 2π/ω = 2 s here. The phase-plane path is a closed ellipse: no energy is lost.

Investigation 7: Light, critical and heavy damping A level

What to look for: k < ω: complex roots −k ± ip, a decaying oscillation. k = ω: a repeated root −ω, the fastest return with no overshoot (car suspension aims near this). k > ω: two real roots, a slow creep back.

Investigation 8: Driving it: resonance A level

What to look for: The particular integral has amplitude F ÷ √((ω² − Ω²)² + (2kΩ)²), largest when Ω is close to ω: resonance. The complementary function dies away, leaving only the particular integral.

Batch experiment 1: Euler's method: error against step size

Close to a straight line through the origin: the error is proportional to h (Euler is a first-order method). To gain one more decimal place, take ten times as many steps.
Theory (≈ eh/2): 0.025: 0.034 · 0.05: 0.068 · 0.1: 0.136 · 0.2: 0.272 · 0.25: 0.34 · 0.5: 0.68
Result from a test run: 0.025: 0.0332 ± 0 · 0.05: 0.065 ± 0 · 0.1: 0.125 ± 0 · 0.2: 0.23 ± 0 · 0.25: 0.277 ± 0 · 0.5: 0.468 ± 0 (mean ± SE, 1 runs each)

Batch experiment 2: Logistic: where do solutions settle?

Every positive start ends very close to 2: it is a stable equilibrium. (Only y = 0 exactly would stay put.)
Theory (stable equilibrium y = 2): 2
Result from a test run: mean 2, SD 3.45e-4, SE 1.99e-5 from 300 runs

Batch experiment 3: Period of SHM (A level)

The period depends only on ω, not on the amplitude: the defining property of SHM.
Theory (2π/ω): 1: 6.28 · 1.5: 4.19 · 2: 3.14 · 3: 2.09 · 4: 1.57 · 6: 1.05 · 8: 0.785
Result from a test run: 1: 6.28 ± 0 · 1.5: 4.19 ± 0 · 2: 3.14 ± 0 · 3: 2.09 ± 0 · 4: 1.57 ± 0 · 6: 1.05 ± 0 · 8: 0.785 ± 0 (mean ± SE, 1 runs each)

Batch experiment 4: Settling time and damping (A level)

With light damping the envelope e^(−kt) sets the time; it is fastest close to critical damping (k = ω ≈ 3.14; for a 1% band, a little below it, since a tiny overshoot is allowed); heavier damping makes it slower again because the slow root of the auxiliary equation creeps back.
